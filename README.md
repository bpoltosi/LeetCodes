# LeetCodes

Repositório de exercícios de algoritmos e estruturas de dados resolvidos ou em estudo a partir de desafios do **LeetCode**, implementados em C.

## Exercícios presentes

| Arquivo | Problema |
|---|---|
| `01-TwoSum.c` | Two Sum |
| `02-PalindromeNumber.c` | Palindrome Number |
| `03-RomanToInteger.c` | Roman to Integer |
| `04-MergedSortedArray.c` | Merge Sorted Array |
| `05-ValidParentheses.c` | Valid Parentheses |

## Objetivo

Praticar decomposição de problemas, implementação de algoritmos, manipulação de arrays e strings, análise de casos-limite e complexidade de tempo e espaço.

## Como utilizar

Os arquivos seguem o formato de funções esperado pela plataforma LeetCode em vários desafios. Eles não necessariamente contêm um programa `main()` independente. Para testar localmente, crie um harness de testes compatível com a assinatura de cada problema ou submeta a função diretamente à plataforma.

## Status

Coleção de exercícios em evolução. A presença de um arquivo não significa que a solução esteja concluída ou validada; confira o código de cada desafio.
